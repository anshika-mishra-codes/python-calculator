# Calculator

A function-based, interactive terminal calculator built in Python.

## About

This project is a menu-driven calculator application that allows users to perform arithmetic operations through an interactive terminal interface. The program is structured using separate functions for each operation and uses a continuous menu loop to handle multiple calculations until the user chooses to exit.

## Features

* Interactive menu-driven interface
* Function-based architecture
* Addition
* Subtraction
* Multiplication
* Division
* Continuous calculations using a loop
* User input handling
* Clean terminal interaction

## What I practiced

While building this project, I focused on:

* Functions and function calls
* Function parameters
* Conditional statements
* Loops
* User input
* Program flow and control

## Tech stack

* Python 3
* Terminal / Console application

This project was built as a practice exercise to strengthen core Python programming concepts through a structured interactive application.
